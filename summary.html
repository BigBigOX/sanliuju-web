1. 核心游戏流程

🦊 选名字 → 🎤 主持 / 🎭 加入 → 房间等待 → 轮一：破冰 → 轮二：配对 → 轮三：默契 → 投票惩罚 → 默契报告

房间机制

  • 房主创建房间 → 自动生成 6 位房间号
  • 玩家输入房间号加入（2-6人，满3人可开局）
  • 同步：同一浏览器通过 BroadcastChannel 多标签页同步
  • 房间状态：waiting → playing → round 1/2/3 → ended

三轮设计

轮次名称题库特殊机制
1破冰轮L1 (30题) — 轻松日常暖心互动，建立好感
2结对轮L2/L3 (60题) — 情感深度二选一配对 + 🔥火花 + 🗡️挖墙脚
3默契轮L4 (30题) — 灵魂拷问投票惩罚 + 投票暖心

2. 视觉动效系统

浮动房间

  • 布局：玩家以圆形头像游离在椭圆轨道上，替代传统 Grid 网格
  • 漂浮动画：每个玩家独立 CSS drift 动画（周期 3-6s，±8px 偏移）
  • 热度引力：高热度玩家对自动靠近，通过 CSS transition 平滑移动 (2.5s)
  • 结算收敛：游戏结束时最高热度对聚拢到中心，带绿色光环
  • 加入闪光：新玩家加入时弹跳动画 + 橙色光环

3. 玩家身份系统

  • 入口：首页显示历史名字列表（localStorage 持久化）
  • 创建：输入名字 + 选 emoji 头像（12 个可选）→ 保存 profile
  • 选择：点击已有名字 → 进入角色选择页（主持/加入）
  • 数据结构：{ id, name, avatar, customPenalties, createdAt, lastUsed }
  • 存储：localStorage key slj_profiles

4. 暖心值与热度系统

暖心值

  • 房主可手动加减玩家暖心值（🪙）
  • 投票暖心环节由全体投票决定谁获得暖心值

热度 (Heat)

  • 计算：每对玩家之间的互动热度 (0-100)
  • 触发：❤️暖心 +10 热度 | 🔥火花 +20 热度
  • 二选一：选择相同的玩家对 +15 热度
  • 引力：热度 > 30 的玩家对在浮动房间中明显靠近
  • 挖墙脚：嫉妒玩家发动后降低最高热度对 20 点

好感 (Crush)

  • 记录谁对谁有好感（发送暖心/火花的目标）
  • 用于计算嫉妒值

嫉妒 (Jealousy)

  • 轮一结束时计算：若有玩家喜欢的人与别人热度高 → 嫉妒 +1
  • 嫉妒值在轮二显示，可消耗发动「挖墙脚」

5. 惩罚系统

惩罚类别

类别图标示例
表演🎭用三种不同的声调唱《小星星》
真心话💬最近一次对谁撒了谎？说了什么？
大冒险⚡做 10 个俯卧撑（或 15 个深蹲）
社交🎯给在场每个人一句真诚的夸奖

惩罚机制

  • 候选池：系统 4 类各抽 1 题 + 所有玩家自定义模板随机抽取
  • 投票：全体玩家投票选出最终惩罚（房主发起）
  • 自定义模板：每个 profile 可编辑自己的惩罚模板（存 localStorage）
  • 显示：投票结束后所有玩家端展示惩罚结果

6. 投票机制

  • 类型：🗳️投票惩罚 / 💗投票暖心
  • 发起：房主在轮三结束后触发
  • 投票：所有玩家各投 1 票，实时显示进度
  • 公布：全员投完后自动公布结果（含票数分布）
  • 消息协议：VOTE_START → VOTE_CAST → VOTE_RESULT

7. 挖墙脚玩法

  • 触发条件：轮二 + 嫉妒值 > 0
  • 效果：消耗 1 点嫉妒值，降低最高热度配对 20 热度
  • 加成：发动者本轮二选一投票权重翻倍
  • UI：玩家端显示黑色「🗡️挖墙脚」按钮，标注剩余次数

8. 玩法指引

准备阶段

  1. 所有人在同一浏览器打开 36.bigbigox.dpdns.org
  2. 各自选择或创建自己的身份（名字+头像）
  3. 一人选「主持聚会」创建房间，其余人选「加入聚会」输入房间号
  4. 满 3 人后主持人点「开始游戏」

轮一：破冰轮（轻松日常）

  • 主持人抽题 → 30 秒计时 → 大家轮流回答
  • 回答过程中可点 ❤️「暖心」表达共鸣（+10 热度）
  • 轮一结束后系统自动计算「嫉妒值」— 你的心动对象和别人热度高？

轮二：配对轮（情感深度 + 二选一）

  • 主持人抽题会同时抽一道二选一（咖啡/茶、山/海…）
  • 大家先做二选一 → 选相同的人之间 +15 热度
  • 可点 🔥「火花」表达欣赏（+20 热度）
  • 嫉妒值 > 0 的玩家可发动「🗡️挖墙脚」— 拆散最高热度对

轮三：默契轮（灵魂拷问 + 投票）

  • 深度问题，检验默契
  • 三轮结束后主持人发起「投票惩罚」或「投票暖心」
  • 全员投票 → 结果公布 → 热度聚类动画
  • AI 自动生成默契报告总结

浮动房间怎么看

  • 圆形房间中玩家头像缓慢漂浮
  • 热度高的两个玩家会逐渐靠近
  • 游戏结束时最高热度对聚拢到中心
  • 挖墙脚发动时最高热度对会弹开
