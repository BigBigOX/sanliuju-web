游戏循环

AI 出题→ 30s 计时→ 自动分析→ 匹配结果→ 阈值检测→ 惩罚投票→ 本轮结算→ 下一轮

自动化流程

  • 计时归零 → 自动触发 AI 分析（800ms 延迟）
  • 分析完成 → AI 匹配结果广播全端
  • 阈值触发 → 自动生成惩罚候选 → 全员投票 → 自动决议
  • 本轮题目达上限 → 自动进入结算（8s 展示延迟）
  • 结算 → AI 生成轮次小结 + 嫉妒值揭晓
  • 进入下一轮 → 1.5s 后自动出首题
  • 三轮完毕 → AI 终审报告

通信协议

方向消息类型
Host → AllGAME_STARTED, QUESTION, TIMER_TICK, TIMER_END, MATCH_RESULT, VOTE_START, VOTE_RESULT, ROUND_SETTLEMENT, ROUND_CHANGED, JEALOUSY_UPDATED, GAME_ENDED, AI_THINKING, ROOM_STATE
Player → HostPLAYER_JOINED, PLAYER_ANSWER, PLAYER_REJOINED, VOTE_CAST, ROOM_STATE_REQUEST

基于 Supabase Realtime Broadcast（PubSub 模式）。Host 浏览器为状态权威源，每隔 3 秒 + 状态变化时广播全量 ROOM_STATE。玩家终端是瘦客户端——只接收广播、提交回答/投票。

消息循环机制 已实现

状态同步策略

  • 每 3 秒：Host 广播完整 ROOM_STATE（room, players, game, heat）
  • 状态变化时：立即广播 ROOM_STATE（玩家加入、计时结束、匹配完成）
  • 玩家重连：发送 PLAYER_REJOINED → Host 重播 ROOM_STATE（5s 超时）

会话持久化

  • localStorage：当前会话信息 + Host 完整备份（30 分钟过期）
  • 刷新恢复：自动检测未完成游戏 → 显示重连横幅 + 相对时间
  • 跨设备：通过 Supabase 实时通道从 Host 恢复状态

AI 架构

AI 主持人 System Prompt DeepSeek

你是三六局（Sanliuju）的AI主持人。你全权负责游戏进程：出题、收集回答、计算匹配度、触发奖惩、生成总结。

第一轮「信息采集」：出轻松诙谐的生活化问题。轮末生成初始匹配矩阵。
第二轮「当下匹配」：聚焦当下场景，根据回答自动生成暖心/火花值。
第三轮「人性博弈」：清空前两轮日志，深度价值观拷问，玩家通过回答悄悄提升匹配度。
输出格式：所有输出必须是 JSON，包含 func 字段指定渲染函数。
风格：幽默、戏精、接地气，问题让人一愣然后笑。
